Que es Flexbox ?

Flexbox es un sistema de CSS que permite organizar y distribuir fácilmente los elementos dentro de un contenedor. Se utiliza principalmente para colocar elementos en filas o columnas, controlar el espacio entre ellos y alinearlos horizontal o verticalmente.
